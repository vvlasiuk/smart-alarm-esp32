# Розумний індикатор тривоги + будильники (ESP32)

Окрема коробочка на столі чи стіні: зелене/червоне світло — поточний стан повітряної тривоги у вашому районі, короткий сигнал зумера — тільки в момент зміни стану. Плюс до 8 незалежних будильників з веб-сторінки, кожен — з опцією «не дзвонити під час тривоги» і дзвінком на підтверджений відбій. Живиться від мережі, а при відключенні світла непомітно перемикається на власний акумулятор.

Джерело даних про тривоги — офіційний [UkraineAlarm API](https://api.ukrainealarm.com).

## Що робить пристрій

- **Зелений LED** — точно відомо, що тривоги немає.
- **Червоний LED** — точно відомо, що тривога активна. Світить завжди, включно з нічним режимом — жодних винятків для цього кольору.
- **Синій LED** — стан невідомий: або йде підключення до Wi-Fi, або понад 2 хвилини не було жодного успішного запиту до API (немає інтернету, не введено токен, сервіс недоступний). Пристрій свідомо не вгадує стан, а чесно каже «не знаю».
- **Зумер** сигналить один раз коротко на початок тривоги і один раз довго на відбій — без безперервного гудіння. Уночі (див. нічний режим нижче) цей короткий сигнал теж мовчить — так само, як мовчать зелений/синій LED.
- До **8 будильників**, кожен з часом, днями тижня і перемикачем «не дзвонити під час тривоги». Якщо дзвінок пропущено саме через підтверджену тривогу — пристрій продзвонить, щойно прийде підтверджений відбій, навіть якщо тривога тривала кілька днів.
- Якщо даних про тривогу немає (збій мережі чи API) — будильник все одно дзвонить за розкладом: краще розбудити зайвий раз, ніж мовчати, покладаючись на дані, яких насправді немає.
- **Нічний режим**: у задане вікно часу (типово 22:00–07:00, налаштовується) зелений і синій LED вимикаються, а короткий сигнал зумера на зміну кольору мовчить — щоб не заважати спати. Керується тим самим годинником NTP, що й будильники — без додаткових датчиків. Червоний LED і будильники (звичайні та на відбій) уночі не приглушуються — працюють на повну.
- Усі налаштування (Wi-Fi, токен API, ID регіону, пароль, будильники, нічний режим) — через вебсторінку пристрою, без перепрошивання.

| Плата ESP32 (DevKit, ESP-WROOM-32) | будь-яка з USB (CP2102/CH340) | ≈280 |
| Зумер 5В | TMB12A05, 85 дБ, 30 мА | ≈12 |
| Транзистор-драйвер зумера | 2N2222, NPN, TO-92 | ≈2 |

| Світлодіоди 5 мм | червоний / зелений / синій, 3 шт | ≈5 |

| Кнопка «Зупинити будильник» | тактова, 2 pin | ≈2 |
| Акумулятор 18650 | незахищений елемент (захист бере на себе UPS-модуль) | ≈230 |

| UPS-модуль (power bank з наскрізним зарядом) | 5В/2А | ≈200 |

Разом — приблизно $20–25.

## Схема підключення

Піни вказані під типовий ESP32 DevKit — за іншої розводки поправте номери в прошивці.

| ESP32 | Компонент | Примітка |
|---|---|---|
| GPIO 27 | LED зелений (анод), через резистор | катод → GND |
| GPIO 26 | LED червоний (анод), через резистор | катод → GND |
| GPIO 14 | LED синій (анод), через резистор | катод → GND |
| GPIO 32 | через резистор 1 кОм → база транзистора 2N2222 | зумер бере ≈30 мА — забагато для GPIO напряму |
| Колектор 2N2222 | мінус (−) зумер-модуля | плюс (+) зумер-модуля — на 5V |
| Емітер 2N2222 | GND | спільна земля з усією схемою |
| GPIO 4 | одна нога кнопки «Зупинити будильник» | друга нога — на GND, підтяжка увімкнена в коді |
| 5V / VIN | вихід UPS-модуля | не на 3.3V |
| GND | спільна земля з UPS-модулем і всіма компонентами | обов'язково спільна для всіх |

> На деяких платах GPIO25 не працює як вихід — перевірте тестовим світлодіодом перед постійним монтажем; якщо не працює, використовуйте інший вільний GPIO (у цій схемі — GPIO32).

## Прошивка й налаштування

1. Встановіть [Arduino IDE](https://www.arduino.cc/en/software).
2. Файл → Налаштування → «Додаткові URL для менеджера плат»:
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
   Потім Інструменти → Плата → Менеджер плат → встановіть **esp32 (Espressif Systems)**.
3. Ескізи → Підключити бібліотеку → Керувати бібліотеками → встановіть **WiFiManager** (tzapu) і **ArduinoJson** (Benoit Blanchon, 6.x).
4. Завантажте `firmware/rozumnyi_bud_indicator_v14.ino` на плату (Wi-Fi, токен, регіон і пароль у код вписувати не треба — усе через веб-форму).
5. Перше ввімкнення: підключіться до тимчасової мережі **«Будильник-Setup»** (пароль за замовчуванням `12345678`), введіть домашню Wi-Fi мережу і токен [UkraineAlarm API](https://api.ukrainealarm.com/api/v3/regions).
6. Далі відкрийте `http://budylnyk.local` у тій самій мережі — там налаштовуються ID регіону, будильники, нічний режим LED і пароль адміністратора (змініть його одразу після першого входу).
7. Скинути Wi-Fi/токен/пароль до типових значень — утримати кнопку **BOOT** ~3 секунди під час увімкнення, або скористатись посиланням «Скинути Wi-Fi і токен наново» на сторінці.

ID регіону за замовчуванням — `152` (Черкаський район). Щоб знайти свій, виконайте запит `GET https://api.ukrainealarm.com/api/v3/regions` зі своїм токеном у заголовку `Authorization` і знайдіть потрібну назву в полі `regionName` — поруч буде `regionId`.

## Живлення й безпека

- Використовуйте **захищений** (protected) елемент 18650, або незахищений — але лише разом з UPS-модулем, що бере захист на себе (як у списку компонентів вище).
- Автономність на одному акумуляторі (2500–3500 мАг) — приблизно 20–30 годин без мережі.
- Пароль на вебсторінці й на мережі «Будильник-Setup» — побутовий захист (щоб сторонній поруч не зміг тихцем змінити налаштування), не захист від цілеспрямованої атаки. Пристрій не повинен дивитись прямо в інтернет.
